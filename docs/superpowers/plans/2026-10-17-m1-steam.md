# Cellar M1 — Steam That Works Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `cellar steam install|start|stop|restart|status` puts Windows Steam into one shared Cellar bottle. Steam boots to sign-in, stays stable after Kamen signs in, downloads games, survives its own self-updates, and recovers from the known failure modes.

**Architecture:**
- A new `SteamStore` in `CellarCore` owns a bottle named `Steam` and drives `Steam.exe` through the existing `BottleStore`/`WineRunner`.
- Health comes from two sources: Steam's own log files, parsed by pure functions, and Wine's `tasklist.exe`, run inside that bottle only.
- Steam runs detached, so `cellar steam start` returns once Steam is up.

**Tech Stack:** Swift 6.3, Swift Testing, swift-argument-parser (as M0); engine `sikarugir-10.0_6-c1` (Wine 10.0), which includes `tasklist.exe`/`taskkill.exe`.

**Spec:** `docs/superpowers/specs/2026-10-17-cellar-design.md` (M1 in section 7, constraints in section 5, lessons in section 8, calls in section 9). M0 code: `Sources/CellarCore/*`, plan `docs/superpowers/plans/2026-10-17-m0-groundwork.md`.

## Global Constraints

- All M0 constraints still hold. In particular:
  - tests and automated runs are invisible and silent;
  - nothing is permanently deleted except Cellar's own temporary files;
  - Cellar never touches Wine outside its root;
  - small tests only;
  - `CELLAR_INTEGRATION=1` gates anything real.
- **Kamen does every login himself** (Steam username, password, Steam Guard). Cellar never reads, stores, types or logs credentials. It may read `connection_log.txt` for the "Logged On" state, but it never prints account ids: replace `[U:1:<digits>]` with `[U:1:…]` in anything it shows.
- **Steam installer source:** only `https://cdn.fastly.steamstatic.com/client/installer/SteamSetup.exe` (Valve's CDN).
- **Steam must stay reachable** (spec section 8). Never pass `-silent`. Steam keeps a visible window, and `cellar steam start` brings it back when it is already running. The phantom second Dock icon is accepted.
- **Steam launch flags:** always `-no-cef-sandbox` (spec section 8).
- **One shared Steam bottle,** named exactly `Steam` (decided here, see Rulings in Task 4). Every Windows game Kamen owns installs into it.
- **Mac Steam.** Kamen's Mac Steam (`/Applications/Steam.app`, process `steam_osx`) holds ports 27060/27036. When it is running, `cellar steam start` prints a warning and carries on. In August, Windows Steam recovered over WebSocket while Mac Steam was running.

## Review Focus

1. **Steam already running.** `cellar steam start` must not start a second Steam. It brings the running one forward, and `status` reports it once (Task 5).
2. **Stale state after an unclean exit.** If the bottle's wineserver is alive but `steam.exe` is not, `start` clears it with `bottle kill` before launching (Task 5).
3. **Webhelper crash loop.** Five or more `Startup - webhelper launched` lines within 10 minutes is a crash loop. `status` reports it as the August failure, with the fix `cellar steam restart`; if it repeats, it's an engine problem (Task 3).
4. **Account ids never shown.** No `[U:1:<digits>]` reaches stdout, the run log or an error message (Task 3).
5. **A bad installer download.** An HTML error page, a cut-off file or a non-PE file is rejected before Wine runs it, and nothing is left in `downloads/` (Task 4).

### Task 4: Install Steam into the shared bottle

**Files:**
- Create: `Sources/CellarCore/SteamStore.swift`, `Tests/CellarCoreTests/SteamStoreTests.swift`
- Modify: `Sources/CellarCore/CellarErrors.swift` (add `SteamError` messages)

**Interfaces:**
- Consumes: `BottleStore.create/run/runner/kill` (M0), `WineRunner.spawn` (Task 2), `SteamLogs` (Task 3)
- Produces:

```swift
public enum SteamError: Error, Equatable { case notInstalled, badInstaller(String), installFailed(String) }
public struct SteamStore: Sendable {
    public static let bottleName = "Steam"
    public static let installerURL = URL(string: "https://cdn.fastly.steamstatic.com/client/installer/SteamSetup.exe")!
    public static let launchFlags = ["-no-cef-sandbox"]
    public init(paths: CellarPaths, bottles: BottleStore, engines: EngineStore,
                installer: URL = SteamStore.installerURL, macSteam: @escaping @Sendable () -> Bool = MacSteam.isRunning)
    public var steamFolder: URL        // <bottle>/prefix/drive_c/Program Files (x86)/Steam
    public var steamExe: URL           // steamFolder/steam.exe, case-insensitive lookup (Valve ships "steam.exe", Sikarugir shows "Steam.exe")
    public func isInstalled() -> Bool
    public func install() async throws  // creates the bottle if missing; no-op if already installed
}
```

- Installer checks run before Wine sees the file:
  - downloaded with `URLSession` to `downloads/SteamSetup.exe.part`;
  - starts with `MZ`;
  - size between 1 MB and 20 MB;
  - HTTP 200 only.

  On any failure the file is removed and `SteamError.badInstaller(reason)` thrown. A `file://` installer URL is copied, for tests.
- Install runs headless: `wine <downloads>/SteamSetup.exe /S`. Afterwards it requires `steamExe` to exist, else `installFailed`. The downloaded installer is removed after a successful install; it is Cellar's own temporary file.
- `SteamError` messages:
  - `notInstalled`: "Steam isn't installed in Cellar yet." Fix: `Run: cellar steam install`.
  - `badInstaller`: "The Steam installer download wasn't valid (<reason>), so nothing was run."
  - `installFailed`: "Steam's installer finished but Steam.exe isn't there (<reason>)." Fix: `See the log: ~/Library/Logs/Cellar/Steam.log`.

```swift
public struct SteamStatus: Equatable, Sendable {
    public var installed: Bool
    public var running: Bool            // "steam.exe" in tasklist
    public var webhelperRunning: Bool   // "steamwebhelper.exe" in tasklist
    public var macSteamRunning: Bool
    public var health: SteamHealth
}
public enum StartOutcome: Equatable, Sendable { case started, broughtForward, clearedStaleStateThenStarted }
public func start() async throws -> StartOutcome
public func stop() async throws                  // steam.exe -shutdown; wait ≤ 30 s for steam.exe to leave tasklist; then bottle kill
public func restart() async throws -> StartOutcome
public func status() async throws -> SteamStatus
public func processes() async throws -> [String] // lowercased image names from `wine tasklist /fo csv /nh`, headless
```

- `MacSteam.isRunning`: `pgrep -x steam_osx` exit 0.
- `start()` logic, in order:
  1. Throw `notInstalled` if needed.
  2. If `macSteam()`, print nothing here; the CLI warns (Task 6).
  3. Read `processes()`:
     - `steam.exe` present → spawn `steam.exe -no-cef-sandbox` (Steam hands it to the running instance, which shows its window) → `.broughtForward`;
     - no `steam.exe` but any process (stale wineserver) → `bottle kill`, then spawn → `.clearedStaleStateThenStarted`;
     - nothing → spawn → `.started`.
  4. Spawn interactive (visible), with `cwd = steamFolder`.
- `status()` reads, from `steamFolder/logs`, the last 256 KB of `connection_log.txt`, `webhelper.txt` and `bootstrap_log.txt` (missing file = empty) into `SteamLogs.health(…, now: Date())`.
